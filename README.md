# 国旗クイズ (Flag Quiz)

世界197の国と地域の国旗を4択で当てるWebゲーム。単一HTML + 純粋JS、ビルド不要です。

## 遊び方

デモURL: https://flag-quiz-58b.pages.dev

国旗を見て、4択の選択肢から正しい国名を選んでください。連続正解でストリーク数を伸ばします。

- **キーボード対応**: 1〜4キーで選択肢を選択可能
- **タッチ対応**: モバイル端末でもボタンをタップして遊べます

## 特徴

- **全197か国・地域**: 国連加盟193か国 + バチカン、パレスチナ、台湾、コソボ
- **スマート出題**: 同地域からダミー選択肢を生成し、より難しく
- **1周重複なし**: ゲーム中に同じ国旗は出題されません
- **ストリーク保存**: ブラウザに最高ストリーク数を保存

## ローカル実行

`index.html` をブラウザで開くだけ。サーバーやビルドツールは不要です。

```bash
open index.html
```

## クレジット

国旗画像は [Flagpedia](https://flagpedia.com) (flagcdn.com) から提供されています。
