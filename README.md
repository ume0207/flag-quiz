# 国旗クイズ (Flag Quiz)

世界197の国と地域の国旗を8択で当てるWebゲーム。単一HTML + 純粋JS、ビルド不要です。

## 遊び方

デモURL: https://flag-quiz-58b.pages.dev

国旗を見て、8択の選択肢から正しい国名を選んでください。ラウンド制（10問または15問）でスコアを競います。

- **キーボード対応**: 1〜8キーで選択肢を選択可能
- **タッチ対応**: モバイル端末でもボタンをタップして遊べます
- **地域別モード**: ぜんぶ（全世界）＋ 6地域（アジア・ヨーロッパ・アフリカ・北米・南米・オセアニア）から選択

## 特徴

- **全197か国・地域**: 国連加盟193か国 + バチカン、パレスチナ、台湾、コソボ
- **8択問題**: より高い難易度。選択肢に「国名（首都）」の形式で表記
- **ラウンド制**: 10問または15問を選べます。リザルト画面で正答率・スコアを確認
- **地域別フィルター**: 興味のある地域だけを集中的に学べます
- **スマート出題**: 同地域からダミー選択肢を生成し、より難しく
- **1周重複なし**: ゲーム中に同じ国旗は出題されません

## ローカル実行

`index.html` をブラウザで開くだけ。サーバーやビルドツールは不要です。

```bash
open index.html
```

## クレジット

国旗画像は [Flagpedia](https://flagpedia.com) (flagcdn.com) から提供されています。
